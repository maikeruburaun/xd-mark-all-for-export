## Mark All Layers for Export v1.1.0

Marks every layer XD allows a plugin to edit, in one click, for Development link handoffs.

### What's new
- **Fix:** marking no longer gets undone in files with masks, components or repeat grids.
- **New:** the results popup lists containers that need one manual step (double-click into the container, then run the plugin again).
- **New:** the **Check what is still unmarked** command reports progress across the whole document.

### Install
Download `MarkAllForExport-v1.1.0.xdx` below and double-click it. XD warns that the plugin is unverified; accept it.

Tested on Adobe XD 61.0.12.1
